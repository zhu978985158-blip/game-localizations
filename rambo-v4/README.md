# 第一滴血（Rambo）汉化 v4 译文与构建工具

本目录用于 **Windows 游戏《第一滴血》（Rambo，安装目录包含 `Rambo.exe`）** 的既有 v4 汉化工作。覆盖界面、字幕与启动器文字，并提供字库制作和文件级校验脚本。它是针对固定原包的制作源码，不能应用到同名其他平台作品，也不是游戏下载。

游戏程序、配音、图片和原有语言资源仍属于原权利人。这里公开的是 Tong 的译文定稿台账和自写工具，不附原 ZIP、游戏、字体、历史客户报告或已经生成的覆盖／恢复文件。原游戏确切发行版本未从这份工程独立核实，**以原包哈希匹配为准**。

## 文件和翻译范围

`逐行校对台账.jsonl` 共 1,474 条定稿：界面 943、字幕 514、启动器 17。每条用表名、物理记录位置和原文定位，`v4_zh` 是构建使用的最终中文；`v1_zh`、`v2_zh` 是已有修改历史，不应代替定稿。无键字幕续句与重复键按原行位置处理。

`build_v4.py` 从自备原 ZIP 中读取原 CSV，确认原文与台账逐行相符，再生成中文 CSV、启动器 GBK 文字、语言配置和 English／Japan 字库。它同时抽取九个原始目标文件到本地恢复目录。`verify_package_v4.py` 核对表头、列数、非目标列、标签、占位符、字形、图集、恢复文件及 ZIP 内容；只有检查通过才生成本地交付包。

`源文件指纹.json` 保存原包及历史构建指纹，原包 SHA-256：

```text
5360feea82f1d7cfb756cd67bd852d082c3a0f9da21996c0533f09f91530a6cd
```

## 自备输入和依赖

需要 Python 3.9+ 和 Pillow。把匹配原包放到 `inputs/Rambo.zip`。还需要一份你有权用于生成和分发字库的中文字库，以 `RAMBO_CJK_FONT` 提供路径：

```sh
export RAMBO_CJK_FONT=/path/to/licensed-CJK-font.ttf
python3 build_v4.py
python3 verify_package_v4.py
```

未设置变量时默认读取 `inputs/CJK-font.ttf`。原制作使用系统字体，本整理副本改为显式自备字体，不附系统字体或生成的字形。**字体变化会改变排版、图集和生成文件哈希**；即使字形覆盖检查通过，也需要重新确认基线、间距与字幕显示，不能用历史成品哈希证明新字体效果。

输入原 ZIP 只读；输出为 `补丁/`、`恢复原版/`、校验报告，以及校验成功后的 `Rambo_汉化补丁_v4/` 和同名 ZIP。最终校验器会删除并重建这个固定交付目录，只应在独立工作目录运行。所有原始资源、字体和构建产物均被本目录 `.gitignore` 排除。

## 安装与恢复

完成全部文件检查后，先退出游戏并备份原文件及存档，在测试游戏副本中将交付目录 `覆盖文件/` 内的 `data`、`loader_data` 合并到 `Rambo.exe` 同级位置，替换同名目标。不得将 `恢复原版/` 和 `覆盖文件/` 同时当成安装内容。

撤回时退出游戏，用同一原包构建出的 `恢复原版/` 内容还原同名文件。恢复包来自你自己提供的原 ZIP，不随 GitHub 仓库分发，也不应重新公开上传。
