# 战争艺术2：全球联盟 扩充地图版中文译表

本目录对应 **J2ME 手机游戏《Art of War 2: Global Confederation》（战争艺术2：全球联盟）的既有扩充地图版**。保存俄文到简体中文的基础译表与自写显示译表生成器，供继续审校和研究中文显示使用。原扩充版的确切发布者、版本及授权未从现有资料独立核实，不能将这份译表当作所有 Art of War 2 JAR 的通用安装补丁。

原游戏来自 Gear Games（译表中的原始版权行如此标示）。中文译文与生成器由 Tong 整理。仓库不附原 JAR、反编译 Java 文件、编译类、模拟器、字体或任何原游戏图片，也不附修改计费流程的工具。

## 内容和维护入口

| 基础资源 | 槽位数（含末尾空槽） | 用途 |
| --- | ---: | --- |
| `d0` | 96 | 任务叙述与对白 |
| `s0` | 115 | 界面／操作短文本 |
| `t0` | 126 | 菜单、帮助与动态文字 |

`文本/*_对照.json` 按 `id/ru/zh` 保存原文和中文；`*_中文.txt` 按同样槽位顺序提供工具输入。另有地图名称和目标译表。

**本公开集使用已有的基础对照稿。** 来源中后期 `t0_中文.txt` 有 10 个槽位将控制字符写成了字面 `{1f}` 等标记，并包含依赖额外程序修改的短信状态说明。本集从既有 `t0_对照.json` 的中文列生成 `t0_中文.txt`，保持原有控制字符及基本译文；没有收录这些后期改动或其生成的动态表。不要把本集误认成“收费短信已经禁用”的版本。

## 生成显示译表

`工具/生成动态译表.py` 需要 Python 3.9+ 标准库。它从自备原 JAR 的 `0/d0`、`0/s0`、`0/t0` 中以 CP1251 读取竖线分隔槽位，与中文槽位数量比较；结合地图和国家名称生成精确字符串映射，同时生成 CP1251 经 Latin-1 解码的显示键变体。

在 `原版/` 中只放一份你有权使用的匹配 JAR，然后从本目录运行：

```sh
python3 工具/生成动态译表.py
```

输出为 `源码/ZhDynamic.java`（**本工具生成的翻译映射类，不是原游戏源码**）及 `文本/动态显示译表.json`。整理副本只补了输出目录的自动创建，原有槽位检查保留。

生成器并不修改原 JAR，也没有完整绘制引擎、调用接入或编译打包流程。中文显示仍需要与具体游戏版本集成并测试的适配层，因此下载本目录后没有可直接覆盖安装的汉化包。修改对照稿时应同步中文文本，保留槽位顺序、空槽、控制字符和 `&` 换行，避免分隔符或占位错位。

## 试用和恢复边界

本目录自身不用安装到游戏。若日后自行集成，保留原 JAR 和 RMS／模拟器记录，另用独立模拟器配置与测试存档，不要覆盖唯一原件。撤回集成版时恢复原 JAR 与原有配置；本生成器没有修改原 JAR 或存档的步骤。
