# High Level Enemies 简体中文翻译工程

原模组作者为 **Dalquist**，原作者页面：[High Level Enemies](https://www.nexusmods.com/skyrimspecialedition/mods/3231)。本目录保存简体中文译文、文字回填工具和中文安装器模板。

## 内容与运行前提

- `数据/译文对照.tsv`：326 条不重复的原文与中文译文。
- `工具/hle_localize.py`：读取对应版本的原插件，提取和回填文字，并校验记录结构及非文字数据。
- `安装器/ModuleConfig.xml`、`安装器/info.xml`：历史 MO2 安装器的中文模板。

工具仅依赖 Python 3 标准库。原模组、游戏文件、模型、贴图、第三方脚本和完整成品包均不在本目录中。

自行从原作者渠道取得对应版本的四份原始 ZIP，保持以下文件名，放入本目录的 `01_原文件/`：

```text
High Level Enemies-3231-1-71.zip
High Level Enemies - Scaled-3231-1-71.zip
High Level Enemies - Raised Ability Caps-3231-1-4.zip
HLE - Increased Max Resists-3231-1-2-1576945821.zip
```

## 生成汉化插件

在本目录运行：

```sh
python3 工具/hle_localize.py
```

输入版本及译文覆盖校验通过后，汉化插件输出至 `02_汉化版/汉化插件/`，检查统计写入 `检查/插件检查.json`；所需输出目录会自动创建。普通版与等级缩放版使用同一份译表，二者是游戏安装时的互斥选项。抗性上限补丁无文字，工具保留其原始字节。

`安装器/` 内的 XML 引用了原资源与插件目录，只是安装器模板，不能将本目录直接作为 MO2 安装包使用。它们也不会由上述命令自动整合为完整 FOMOD 包。

## 验证范围

2026 年 10 月 18 日的历史制作记录记载：326 条独立译文覆盖 814 个文字字段，7 个插件完成汉化。这是原交付工程的记录，本次整理没有重新从原包生成插件或重建完整交付包。

本次实际检查了译表的 326 条记录、非空中文、数字与百分比及标记保留，并解析两份 XML。使用合成 NPC 记录验证了 FULL/SHRT 中文回填、非文字 DATA 和记录身份保持、截断字段拒绝；还在临时目录验证了入口会创建插件输出及检查报告目录。

未在 Windows 的 MO2 或 Skyrim SE 内实测字体、界面宽度、实际敌人显示、存档与其他模组兼容性。静态和合成数据检查不能替代游戏内验证。

整理副本将项目路径调整为当前目录，并补充检查报告目录的自动创建；原始制作工程未改动。
