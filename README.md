## 使用

先阅读对应项目说明，并自行准备匹配版本的原 Mod。脚本依赖的原包和游戏资源不随仓库提供；安装器 XML 仅是制作模板，下载此仓库不能直接作为成品 Mod 安装。

High Level Enemies 使用 Python 3 标准库；微风阁的安装器脚本还需要 `lxml`。输入原包、生成文件与检查报告已列入忽略规则。请在独立工作目录中制作，避免覆盖正在使用的游戏或模组文件。
